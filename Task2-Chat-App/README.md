# Real-Time Chat Application

## Description
A real-time chat application built using Socket.IO and Node.js that allows multiple users to communicate instantly.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Socket.IO

## Features
- Real-time messaging
- Multi-user support
- Frontend and backend integration
- Responsive interface

## How to Run

1. Install dependencies

npm install

2. Start server

node server.js

3. Open browser

http://localhost:3000
