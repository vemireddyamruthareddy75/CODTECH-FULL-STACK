# Real-Time Chat Application

## Description
A real-time chat application built using Socket.IO and Node.js that allows multiple users to communicate instantly.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Socket.IO

## Features
- Real-time messaging
- Multi-user support
- Frontend and backend integration
- Responsive interface

## How to Run

1. Install dependencies

```bash
npm install
```

2. Start the server

```bash
node server.js
```

3. Open the app in your browser

```text
http://localhost:3000
```
