# Productivity Tracker Chrome Extension

## Description

A Chrome Extension that tracks website usage and provides productivity analytics.

## Features

- Website time tracking
- Productive and unproductive website classification
- Productivity report dashboard
- Chrome Extension API integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Chrome Extension API

## How to Run

1. Open Chrome
2. Visit chrome://extensions
3. Enable Developer Mode
4. Click Load Unpacked
5. Select Task4-Chrome-Extension folder
