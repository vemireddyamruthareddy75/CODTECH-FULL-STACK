# Real-Time Collaborative Document Editor

## Description

A collaborative document editor built using React, Node.js, and Socket.IO that allows multiple users to edit the same document in real time.

## Features

- Real-time text synchronization
- Multi-user collaboration
- React frontend
- Node.js backend
- Socket.IO integration

## Technologies Used

- React.js
- Node.js
- Express.js
- Socket.IO

## How to Run

### Backend

cd server
npm install
node server.js

### Frontend

cd client
npm install
npm run dev
