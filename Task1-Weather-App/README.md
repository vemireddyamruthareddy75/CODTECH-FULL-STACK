# Weather App

## Description
A responsive weather application that fetches real-time weather data using a public API and displays:

- Temperature
- Humidity
- Feels Like Temperature

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API

## Features
- Real-time weather information
- Responsive design
- User-friendly interface

## How to Run
1. Open index.html using Live Server.
2. Enter a city name.
3. Click Search.
